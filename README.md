# CompanionShelf preview

A teacher-review preview of CompanionShelf. This repository contains the built website; the application source is maintained in a separate private repository.

Visit https://lenguajelabs-design.github.io/Companion-Shelf-Preview/

The site contains independently written companion guidance and source references. Consult school-authorized original curriculum materials for the full publisher lessons, texts and charts. Original publisher books and teacher documents are not distributed here.

Bookmarks, notes and taught status stay in each visitor's browser. They do not sync between devices or with colleagues.
